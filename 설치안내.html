❓ 자주 묻는 질문
설치 팝업이 안 떠요. 어떻게 하나요?+
기기와 브라우저 버전에 따라 자동 팝업이 안 뜰 수 있습니다. 이럴 때는 앱 안에서 더보기 → 설정 → "홈화면에 설치하기"를 누르면 안내 화면이 뜹니다. 그래도 안 되면 브라우저 메뉴(⋮ 또는 ☰)에서 직접 "홈 화면에 추가" / "앱 설치" / "페이지 추가"를 찾아 눌러주세요.
크롬과 삼성 인터넷 중 어떤 걸 써야 하나요?+
두 브라우저 모두 완전히 지원되며 기능 차이는 없습니다. 갤럭시를 쓰신다면 이미 설치되어 있는 삼성 인터넷을 그대로 쓰셔도 되고, 평소 쓰시는 브라우저로 설치하시면 됩니다. 단, 한 번 설치한 뒤에는 같은 브라우저로 계속 사용하시는 것을 권장합니다.
이미 크롬으로 설치했는데 삼성 인터넷으로도 설치해도 되나요?+
가능하지만 두 개의 별도 아이콘이 생기고, 기록(데이터)이 서로 공유되지 않습니다. 브라우저별로 저장 공간이 나뉘기 때문입니다. 헷갈리지 않도록 한 브라우저만 골라 설치하시길 권장합니다.
아이폰에서는 왜 자동 설치 팝업이 없나요?+
iOS(아이폰)의 Safari는 정책상 자동 설치 팝업을 지원하지 않습니다. 대신 공유 버튼(□↑) → "홈 화면에 추가"를 직접 눌러 수동으로 설치해야 합니다. Safari가 아닌 다른 브라우저(크롬 등)로는 아이폰에서 홈 화면 설치가 되지 않으니 꼭 Safari를 사용해주세요.
인터넷이 안 되는 곳에서도 쓸 수 있나요?+
네. 처음 한 번 앱을 열어 설치한 뒤에는 인터넷 연결 없이도 감사 일기 작성, 나눔 기록, 전도 대상자 관리 등 모든 기능을 오프라인으로 사용할 수 있습니다.
앱이 업데이트되면 다시 설치해야 하나요?+
아니요. 인터넷에 연결된 상태에서 앱을 열면 새로운 내용이 자동으로 반영됩니다. 다시 설치하실 필요가 없습니다.
휴대폰을 바꾸면 기록이 자동으로 넘어가나요?+
자동으로 넘어가지 않습니다. 모든 기록은 현재 휴대폰 안에만 저장되기 때문입니다. 기기를 바꾸시기 전에 더보기 → 설정 → "백업 파일 내보내기"로 JSON 파일을 저장해두시고, 새 기기에서 앱 설치 후 "백업 파일 복원"으로 불러오시면 됩니다.
작성하다가 실수로 화면을 나가면 입력한 내용이 사라지나요?+
아니요. 감사 일기·나눔 기록 등 작성 중이던 내용은 자동으로 임시 저장되며, 같은 입력창을 다시 열면 이어서 작성할 수 있습니다.
홈 화면 아이콘을 눌렀는데 주소창이 보여요. 설치가 잘못됐나요?+
주소창이 보인다면 홈 화면 설치가 아니라 단순 바로가기로 추가된 경우입니다. 홈 화면의 아이콘을 삭제하신 뒤, 이 안내를 다시 처음부터 따라 "설치" 과정을 완료해주세요. 정상 설치되면 주소창 없이 전체 화면으로 열립니다.
여러 사람이 같은 휴대폰에서 각자 써도 되나요?+
기록이 한 곳에 저장되므로 한 휴대폰은 한 사람이 사용하시는 것을 권장합니다. 가족이 함께 쓰시려면 각자의 휴대폰에 따로 설치하시는 것이 좋습니다.
